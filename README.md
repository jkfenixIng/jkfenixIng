## Cómo trabajo

- **Arquitectura primero, código después.** Monolito modular antes que microservicios por moda: un despliegue, fronteras explícitas entre módulos y pruebas que verifican que esas fronteras siguen en pie.
- **El contrato es el producto.** Cuando otro equipo consume mi API, la entrega incluye contrato generado, catálogo de errores, ejemplos sacados de ejecuciones reales y trazabilidad de historias de usuario.
- **Code-first y portable.** El esquema sale del código y el modelo no queda casado con las particularidades de un proveedor gestionado.
- **Verificación antes que opinión.** Percentiles y no promedios, hallazgos con pasos de reproducción, builds con advertencias tratadas como errores.
- **Estándares escritos.** Cada proyecto trae la skill que declara cómo se trabaja en él, para que el criterio no viva solo en quien lo pensó.
